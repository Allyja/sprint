---
name: submit-check
description: 제출 전 최종 점검. 필수 파일·실행 확인·문서·결정 기록을 확인하고, Ally가 서술형에 대비해 설명할 수 있게 요약한다. "제출 점검", "submit"에 사용.
---

1. 과제 안내의 필수 제출물 목록과 실제 파일을 대조 (경로·파일명 정확히).
2. 처음부터 실행 재현: 설치/실행 명령을 실제로 돌려 동작 확인. 실패하면 고칠 수 있는 것만 고치고 나머지는 문서에 한계로 명시.
3. 제출 문서(과제가 요구한 형식)에 다음이 있는지 확인: 선택한 판단과 근거, 검증 결과, 남은 한계.
4. 비밀값·키·불필요한 대용량 파일·임시 파일이 없는지 확인.
5. Ally용 **설명 카드** 출력 (서술형은 AI 없이 Ally가 직접 답한다):
   - 무엇을 만들었나 (2줄)
   - 핵심 결정 3개: 무엇을 / 왜 / 대안
   - 검증 방법과 결과
   - 한계와 다음에 할 일
   - 요구사항과 구현이 다른 부분이 있다면 그 이유
6. 👉 Ally: 저장 상태 "저장됨" 확인 → "제출하고 문제풀기".
