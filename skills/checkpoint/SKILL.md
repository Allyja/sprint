name: checkpoint
description: 진행 중 점검. 남은 시간 대비 요구사항 달성 현황을 보고 스코프 조정을 제안한다. "체크", "checkpoint", "지금 어디야"에 사용.
---

1. `date`로 경과/남은 시간 계산.
2. `notes/PLAN.md` 체크리스트를 실제 상태로 갱신 (검증된 것만 체크).
3. 보고 (5줄 이내):
   - ⏱ 경과/남음 · 현재 Phase
   - 완료(검증됨) / 진행 중 / 미착수
   - 위험 1개와 대응
   - 스코프 조정 권고 (필요 시: 무엇을 버릴지)
   - 다음 30분 할 일
4. `notes/DECISIONS.md`에 빠진 결정이 있으면 추가.
