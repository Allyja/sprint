PROBLEM.md의 사용자 관점으로 핵심 화면만 점검한다. 항목별 OK/NG 판정 후 NG 중 영향 큰 순으로 최대 5개만 고친다.

1. 첫 화면에서 무엇을 하는 서비스인지 3초 안에 보이는가
2. 핵심 행동(버튼·입력)이 눈에 띄고 라벨이 명확한가
3. 상태: 빈 데이터 / 로딩 / 오류 / 성공 피드백이 모두 있는가
4. 오류 문구가 원인과 다음 행동을 알려주는가 (한국어, 쉬운 말)
5. 대비·글자 크기가 읽기 쉬운가, 클릭 영역이 충분한가
6. 좁은 화면에서 깨지지 않는가 (가로 스크롤 없음)
7. 간격·정렬·색 사용이 일관적인가

고친 뒤 Browser 미리보기에서 확인할 절차를 `👉 Ally:`로 안내한다.
