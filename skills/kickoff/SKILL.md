---
name: kickoff
description: 시간 제한 과제 시작 직후 실행. 과제 문서를 읽고 요구사항을 정리한 뒤 문제 정의 인터뷰로 넘어간다. "시작", "킥오프"에 사용.
---

1. README·과제 안내·제공 코드를 끝까지 읽는다.
2. `notes/PLAN.md` 작성: 과제 한 줄 요약 / 필수 요구사항 `- [ ] R1 …`(문서 근거) / 선택 요소 / 제출물 파일명·경로(문서 그대로) / 평가 힌트.
3. Ally에게 5줄 보고 후 `grilling` 방식으로 문제 정의 인터뷰를 시작한다. 시간 제한: 10분, 최대 2~3라운드.
   - 질문 축: 사용자 / 진짜 문제 / 성공 기준 / 할 것·안 할 것 / 위험한 가정.
   - 문서로 답할 수 있는 건 직접 찾는다. 업무 맥락은 `👉 Ally: 담당자에게 물을 질문`으로 넘긴다.
4. 합의되면 `notes/PROBLEM.md`에 위 5개 축으로 정리하고 PLAN의 요구사항을 맞춰 갱신한다.
