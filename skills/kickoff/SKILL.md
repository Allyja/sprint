---
name: kickoff
description: 시간 제한 과제 시작 직후 실행. 과제 문서를 읽고 요구사항 체크리스트, 담당자 질문, 시간 계획을 notes/PLAN.md로 만든다. "시작", "kickoff", "과제 읽어줘"에 사용.
---

1. `date` 실행 → `notes/CLOCK`에 시작 시각 기록.
2. 작업 폴더 구조를 확인하고, README·과제 안내·제공 코드를 **전부** 읽는다.
3. `notes/PLAN.md`를 아래 구조로 작성한다:
   - 과제 한 줄 요약 (누구의 어떤 문제를 푸는가)
   - 필수 요구사항 체크리스트 `- [ ] R1 …` (문서 근거 위치 포함)
   - 선택/가산 요소
   - 제출물: 필수 파일명·경로·형식 (문서 그대로 인용)
   - 평가 힌트로 보이는 문장
   - 업무 담당자에게 물을 질문 (최대 5개, 중요도순)
   - 기술 접근 권고안 1개 + 시간 배분
4. Ally에게 5줄 이내로 보고: 과제 요약 / 가장 위험한 부분 / 먼저 물어볼 질문 / 첫 30분 계획.
